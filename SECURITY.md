# Security policy

## Reporting a vulnerability

Email **security@defaultprivacy.com** with a description, the steps to reproduce it, and the impact you expect. Please do not open a public issue for a security problem.

We aim to acknowledge reports within a week and to fix confirmed issues as fast as their severity calls for. We do not run a paid bug bounty, but we will credit you in the fix if you would like.

## Scope

- The website at https://defaultprivacy.com and its API under `/api/`
- The MCP server at https://mcp.defaultprivacy.com
- The code in this repository

Out of scope: denial-of-service testing, automated scanning that generates heavy traffic, and third-party services we link to.

## Contact file

Our security contact is also published at https://defaultprivacy.com/.well-known/security.txt.
