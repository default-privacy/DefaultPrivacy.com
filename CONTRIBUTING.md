# Contributing

Thank you for helping. Default Privacy depends on being right, so every change needs a source.

## Suggest a tool

Open an issue with the **Suggest a tool** form. Include the tool's official website, what it does for privacy, and links to its own documentation for the claims you make (open source, encryption, what it collects). We do not accept affiliate or referral links, and no one can pay to be listed.

## Report a mistake

Open an issue with the **Report a correction** form. Tell us the page, what is wrong, and a link to the source that shows it. We would rather fix a claim than defend it.

## Code changes

Small fixes are welcome as pull requests. Before you open one:

1. Run `bun run test` and `npx tsc --noEmit`, and make sure both pass.
2. Keep each pull request to one change.
3. For guide text, link every factual claim to its source, and follow the style of the existing guides.
